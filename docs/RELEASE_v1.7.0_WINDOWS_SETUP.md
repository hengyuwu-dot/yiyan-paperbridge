# 译研 · Windows 一键安装

**只下载一个安装向导，选择 4B 或 14B，点击“下载并安装”，其余步骤自动完成。**

## 开始使用

1. 在下方 Assets 下载 **`Yiyan-Windows-OneClick-Setup.exe`**。
2. 双击打开，选择 **4B 标准版**或 **14B 精译版**。
3. 点击 **下载并安装**，等待向导完成。
4. 打开译研，导入论文即可离线翻译。

向导自动获取完整安装包、校验全部文件并安装模型、阅读组件、字体与排版环境。支持暂停、断点续传和网络中断自动重试，默认在安装成功后清理下载缓存。

| 配置 | 4B 标准版 | 14B 精译版 |
| --- | --- | --- |
| 完整内容下载量 | 约 4.07GB | 约 10.49GB |
| 内存最低 / 建议 | 16GB / 16GB+ | 24GB / 32GB+ |
| NVIDIA 加速显存最低 / 建议 | 6GB / 8GB+ | 12GB / 16GB+ |
| 安装预留空间 | 15GB | 30GB |

两版都支持 CPU；显存配置用于 NVIDIA GPU 加速。支持 Windows 10 2004+ / Windows 11、Intel / AMD x64、AVX2 处理器。首次下载安装需要联网，安装完成后的论文翻译在本机离线运行。

需要为离线电脑准备完整安装文件时，可选择原有 [4B 完整离线包](https://github.com/hengyuwu-dot/yiyan-paperbridge/releases/tag/v1.6.0-windows-4b-offline)或 [14B 完整离线包](https://github.com/hengyuwu-dot/yiyan-paperbridge/releases/tag/v1.6.0-windows-14b-offline)。
