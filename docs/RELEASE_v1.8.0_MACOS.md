# 译研 · Mac 一键安装

**[下载 Mac 一键安装器](https://github.com/hengyuwu-dot/yiyan-paperbridge/releases/download/v1.8.0-macos/Yiyan-Mac-OneClick-Setup.dmg)**

1. 打开下载的 DMG，双击“安装译研”。
2. 选择 **4B 标准版**或 **14B 精译版**，点击 **下载并安装**。
3. 向导自动准备应用、模型与排版环境；完成后打开译研，即可离线翻译论文。

支持暂停续传、完整文件校验，默认在安装成功后清理下载缓存。

模型独立保存在本机“资源库/Application Support/PaperBridge-Offline/models”。软件菜单 **译研 → 检查更新**可检查新版本，更新只替换应用与运行环境，继续使用现有模型、论文和设置。

| 配置 | 4B 标准版 | 14B 精译版 |
|---|---|---|
| Mac | Apple Silicon（M 系列） | Apple Silicon（M 系列） |
| 系统 | macOS 26.2 或更新 | macOS 26.2 或更新 |
| 建议统一内存 | 16GB 或更多 | 24GB 或更多 |
| 模型下载量 | 约 2.15GB | 约 7.86GB |
| 安装预留空间 | 15GB | 30GB |

首次安装需要联网。模型、字体、排版与推理环境准备好后，翻译和 PDF 导出在本机离线运行。
