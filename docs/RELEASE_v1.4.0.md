# 译研 1.4 · 完整离线 Mac 版

**跨越语言，读懂研究。**

译研将 SCI 英文论文翻译、专业术语、中英对照和 PDF 导出整合为一个简洁的 Mac 论文工作室。内置 **Qwen3-14B 4bit 精译模型**和 **Qwen3-4B 4bit 标准模型**，在你的 Mac 上完成全文翻译。

![译研论文工作室](https://github.com/hengyuwu-dot/yiyan-paperbridge/blob/main/docs/images/workspace.jpg?raw=true)

## 本版功能

- 全文段落翻译、译后复核与润色。
- 五类学科词表、自定义专业译名与本篇术语。
- 中英双栏阅读、同步翻页和滚动、独立或联动缩放。
- 多篇 PDF 队列翻译、段落校订、中文及双语 PDF 导出。
- 翻译用时、运行内存、固态空间统计和可选清理。

![原文与中文译文对照](https://github.com/hengyuwu-dot/yiyan-paperbridge/blob/main/docs/images/bilingual-reader.jpg?raw=true)

## 下载与安装

完整离线应用约 **9.50GB**，包含模型、排版资源、字体与运行环境。

1. 在下方 **Assets** 下载 `Yiyan-1.4.0-AppleSilicon-Offline-14B.tar.gz.part001` 至 `.part006` 全部 6 个分卷，以及 **Full-Mac-Merge-Tools.zip**。
2. 解压工具，把 6 个分卷放进“合并工具”文件夹，双击 **合并完整应用.command**。
3. 合并工具校验并生成完整 `.tar.gz` 文件，打开并解压后，将 **译研.app** 拖入“应用程序”。

**[查看完整 Mac 安装与使用教程 →](https://github.com/hengyuwu-dot/yiyan-paperbridge/blob/main/docs/MAC_INSTALL.md)**

配置：**Apple Silicon · macOS 26.2+ · 14B 精译建议 24GB 或更多统一内存 · 安装时建议预留 35GB 可用空间**。
