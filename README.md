# 译研 · PaperBridge

### 跨越语言，读懂研究。

译研是一款面向 SCI 论文阅读的桌面应用，将英文科研 PDF 翻译成自然、专业的中文，把全文翻译、专业术语、中英对照和 PDF 导出放进一个简洁的论文工作室。

内置 **Qwen3-14B 4bit 精译模型**与 **Qwen3-4B 4bit 标准模型**，在你的 Mac 上完成翻译。完整离线版包含模型、排版资源、字体与运行环境，安装后即可开始阅读。

**[下载完整 Mac 版](https://github.com/hengyuwu-dot/yiyan-paperbridge/releases/tag/v1.4.0-offline-14b)** · **[Mac 安装教程](docs/MAC_INSTALL.md) · [Windows 安装教程](docs/WINDOWS_INSTALL.md)** · **[使用方法](#开始阅读)**

![译研 Mac 论文工作室](docs/images/workspace.jpg)

## 为科研阅读而设计

| 功能 | 使用体验 |
| --- | --- |
| 全文英译中 | 按论文段落处理正文，结合上下文生成中文译文，支持译后复核与润色。 |
| 专业术语 | 提供通用科研、天文与物理、医学与生命科学、材料与化学、工程与计算机词表；支持自定义译名与本篇术语。 |
| 论文排版 | 在论文版面中呈现中文，保留页面尺寸、图片、表格线和公式组件的阅读结构。 |
| 双栏阅读 | 左侧原文、右侧译文，同步翻页与滚动；两侧可以独立放大，也可以联动缩放。 |
| 批量处理 | 一次导入多篇 PDF，按队列依次翻译，每篇论文单独保存。 |
| 阅读与校订 | 在版面对照和段落译文之间切换，修改中文后保存并更新 PDF。 |
| 多种导出 | 导出中文 PDF、原译页交替的双语 PDF，以及完整译文与核对记录。 |
| 资源管理 | 显示翻译用时、运行内存与固态空间，支持按类别清理和完成后自动清理。 |

## 看看译研

### 原文与译文，一起翻阅

左右对照示例论文，图表、公式与文字处在熟悉的位置。开启专注阅读，把窗口空间留给论文。

![原文与中文译文对照阅读](docs/images/bilingual-reader.jpg)

### 为你的学科，选择准确的词

搜索中英文术语，选择学科词表，加入你认可的专业译名。自定义词表用于后续翻译，本篇术语服务于当前论文的语境。

![专业术语词库与自定义译名](docs/images/terminology.jpg)

### 内存、存储与清理，都在一个地方

查看软件占用和固态空间，选择闲置内存、临时排版文件、旧自动备份、下载缓存或运行日志进行清理。

## 安装到 Mac

| 项目 | 配置 |
| --- | --- |
| 芯片 | Apple Silicon，M 系列 Mac |
| 系统 | macOS 26.2 或更新版本 |
| 内存 | 14B 精译建议 24GB 或更多统一内存 |
| 下载大小 | 完整离线应用约 9.50GB，分为 6 个下载分卷 |
| 可用空间 | 安装过程中建议预留 35GB，用于分卷、合并归档与应用 |

1. 打开 **[下载页面](https://github.com/hengyuwu-dot/yiyan-paperbridge/releases/tag/v1.4.0-offline-14b)**，下载 `.part001` 至 `.part006` 全部 6 个分卷，以及 `Full-Mac-Merge-Tools.zip`。
2. 解压合并工具，将全部分卷放进解压后的“合并工具”文件夹，双击 `合并完整应用.command`。
3. 工具校验并合并文件后，打开生成的 `Yiyan-1.4.0-AppleSilicon-Offline-14B.tar.gz`，解压得到“译研.app”。
4. 将“译研.app”拖入“应用程序”，双击打开译研。

**[查看完整图文安装与使用教程 →](docs/MAC_INSTALL.md)**

## 开始阅读

1. **导入论文**：点击“选择论文 PDF”，或将一篇、多篇英文 PDF 拖入工作室。
2. **选择设置**：选择论文领域、翻译页码与本地模型；在“更多设置”中设置译后复核和自动清理。
3. **开始翻译**：点击“开始翻译”。批量导入后，点击“翻译待处理论文”。
4. **对照阅读**：使用左右阅读区翻页、缩放，或进入“段落译文”查看和修改中文。
5. **保存译稿**：从“导出”菜单选择中文 PDF、双语 PDF 或完整译文与核对记录。

专业译名可按下面的格式添加到术语表：

```text
circumstellar medium = 星周介质
progenitor = 前身星
light curve = 光变曲线
```

## Windows 版：4B / 14B 自选

[下载 Windows 版](https://github.com/hengyuwu-dot/yiyan-paperbridge/releases/tag/v1.5.0-windows) · [安装与使用教程](docs/WINDOWS_INSTALL.md)

Windows 版在首次打开时选择下载 4B 标准或 14B 精译模型，之后可以在每篇论文的翻译设置中切换。内置 CPU 与 NVIDIA CUDA 推理组件，并显示电脑内存和显存。

| 配置 | 4B 标准 | 14B 精译 |
| --- | --- | --- |
| Windows 系统 | Windows 10 2004+ / 11，x64 | Windows 10 2004+ / 11，x64 |
| 内存最低 / 建议 | **16GB / 16GB+** | **24GB / 32GB+** |
| NVIDIA 显存最低 / 建议 | **6GB / 8GB+** | **12GB / 16GB+** |
| 模型大小 | 约 2.50GB | 约 9.00GB |
| 安装使用预留空间 | 15GB | 30GB |

两种模型都支持 CPU，显存要求用于完整 GPU 加速。配置按 Q4_K_M、8192 上下文、单任务预留开销；同时安装两种模型留 40GB 空间。更多选择方法见 Windows 教程。
